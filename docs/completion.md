# completion

Read when: installing shell completions.

`whatscli completion` emits shell completion scripts generated by Cobra.

## Commands

```bash
whatscli completion bash [--no-descriptions]
whatscli completion zsh [--no-descriptions]
whatscli completion fish [--no-descriptions]
whatscli completion powershell [--no-descriptions]
```

## Examples

```bash
source <(whatscli completion bash)
source <(whatscli completion zsh)
whatscli completion fish | source
whatscli completion powershell | Out-String | Invoke-Expression
```

For persistent installation paths, run the specific command with `--help`; Cobra prints shell-specific setup instructions.
